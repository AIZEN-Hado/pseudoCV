# Intake questions

Ask in at most 2 messages. Group the questions, and say they can skip anything they don't have.

## Always ask in the first message
> Besides a **ready-now resume** built only from your real work, do you also want a **target resume**? It shows
> what a perfect resume for this JD looks like, including projects you'd still need to build. It's a plan to work
> towards, not something to send yet. (yes / no)

## Path A: the user has a resume
1. Read the resume (use code execution for PDF or DOCX) and extract:
   - **Contact:** name, phone, email, LinkedIn, GitHub, LeetCode, portfolio, city
   - **Education:** college, degree, branch, years, CGPA, 12th and 10th (board, school, year, %)
   - **Experience:** title, company, location, dates, work done, results
   - **Projects:** name, what it does, stack, links, numbers
   - **Skills, certifications, achievements**
2. Show the extracted details compactly and ask for corrections.
3. In the same message, ask only for what's missing:
   - **Experience or internships:** "Do you have any experience or internships not listed? Describe them, or upload an offer or experience letter."
   - **12th and 10th marks:** board, school, year, %.
   - **GitHub username:** if missing, or if the resume says "GitHub" with no URL.
   - **Achievements:** hackathons, coding contest ranks, awards, scholarships, positions of responsibility, publications.
   - **Certifications** not already listed.

## Path B: no resume
Message 1:
1. Full name, phone, email, city
2. LinkedIn, GitHub, LeetCode or portfolio URLs (any you have)
3. College, degree, branch, start and end year, CGPA
4. 12th: board, school, year, %
5. 10th: board, school, year, %

Message 2:
6. Experience or internships: title, company, dates, what you did, results (or "none")
7. Projects: name, repo link, what it does, stack, any results
8. Skills you're comfortable with
9. Certifications (name and issuer)
10. Achievements

## If an answer is missing
- **Optional items** (LeetCode, portfolio, achievements, certifications): drop that line or section from the template.
- **Required items** (name, email, college, degree): ask once more before writing the resume.
